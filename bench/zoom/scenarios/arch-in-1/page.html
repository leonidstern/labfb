labit: how it is put together

Where a pin goes

Every pin goes straight to the listening session. There is no quick model in between.

MCP server

lib/mcp.mjs, with --proxy in lib/proxy.mjs and dev-server finding in lib/devserver.mjs. Each is loaded only when it is used.

Comments store

One JSON file per page in .lab/comments/. A new comment rewrites only its page's file. Done threads with nothing new in 30 days move to .lab/archive/.
