Page keys: cases

Pages are keyed by their file: Pricing.html is /pricing, a/index.html is /a/index. Anything the page format doesn't allow (dots, spaces, other scripts) is spelled as _ and its hex bytes. The code is keyFor in src/key.mjs.

  • Pricing.html should be /pricing. Fails.
  • a b.html should be /a_20b. Passes.
  • a/index.html should be /a/index. Passes.
